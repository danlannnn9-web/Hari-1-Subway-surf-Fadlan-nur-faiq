A. Prompt Engineering

Prompt Engineering adalah teknik memberikan instruksi atau masukan kepada AI agar menghasilkan jawaban sesuai dengan kebutuhan pengguna.

Dalam memberikan instruksi kepada AI, terdapat empat hal penting yang perlu diperhatikan:

1. Role: Menentukan peran AI, misalnya sebagai guru, programmer, atau desainer.
2. Task: Menjelaskan tugas yang harus dikerjakan oleh AI.
3. Context: Memberikan informasi atau latar belakang agar AI memahami kebutuhan pengguna.
4. Format: Menentukan bentuk jawaban yang diinginkan, seperti paragraf, tabel, atau poin-poin.

Memberikan konteks yang jelas sangat penting agar AI tidak membuat asumsi sendiri dan dapat menghasilkan jawaban sesuai dengan keinginan pengguna.

Keuntungan Prompt Engineering:

1. Meningkatkan performa model AI.
2. Mengurangi bias dan respons yang tidak sesuai.
3. Meningkatkan kontrol dan konsistensi jawaban.
4. Memberikan pengalaman penggunaan AI yang lebih baik.

B. Git dan GitHub

Git adalah Version Control System (VCS) yang digunakan untuk melacak perubahan pada file, termasuk siapa yang mengubah, kapan perubahan dilakukan, dan apa saja yang diubah.

GitHub merupakan platform untuk menyimpan dan mengelola repository Git secara online sehingga dapat diakses dan dikerjakan bersama orang lain.

Tiga Working Area dalam Git:

1. Working Directory: Tempat pengguna membuat atau mengubah file.
2. Staging Area: Tempat menyiapkan perubahan sebelum disimpan.
3. Git Directory (Repository): Tempat Git menyimpan riwayat perubahan yang sudah di-commit.

Perintah Dasar Git:

Perintah| Fungsi
"git init"| Membuat repository Git baru.
"git add ."| Memasukkan semua perubahan ke staging area.
"git commit -m "message""| Menyimpan perubahan ke riwayat repository.

Perintah Menghubungkan Git dengan GitHub:

Perintah| Fungsi
"git remote add origin URL"| Menghubungkan repository lokal dengan repository GitHub.
"git push origin main"| Mengirim perubahan ke GitHub.
"git pull origin main"| Mengambil dan menggabungkan perubahan dari GitHub.
